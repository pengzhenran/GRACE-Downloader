# GRACE Downloader 使用说明

GRACE / GRACE-FO 卫星重力 **Level-2 球谐系数下载器**(GUI)。

---

## 一、软件简介

本软件用于从 NASA PODAAC 下载 GRACE 与 GRACE-FO 的 Level-2 月度重力场球谐系数
(GSM 文件),并可一键下载 GRACE 技术说明(TN-13 / TN-14)中的**低阶项改正数据**。

主要功能:

- 下载 **60 阶(BA01)** 或 **96 阶(BB01)** 的 GSM 球谐系数文件
- 三家处理中心:**CSR / JPL / GFZ**
- 覆盖 **GRACE**(2002–2017)与 **GRACE-FO**(2018 至今)
- 一键下载最新技术说明文件(**TN-13** 度1 地心、**TN-14** C20/C30 SLR)

> **说明**:本软件仅负责**数据下载**。由球谐系数到等效水高(EWH)的转换需要额外的
> 处理与改正(如冰后回弹 GIA 等),不在本软件范围内。

---

## 二、使用前准备

1. 注册 NASA Earthdata 账号:<https://urs.earthdata.nasa.gov/users/new>
2. 确认电脑可访问外网(Earthdata 服务器位于海外)

## 三、界面与操作

### 1. 配置区(Configuration)

| 项 | 说明 |
|----|------|
| Earthdata 用户名 / 密码 | 你的 NASA 账号 |
| Target Directory | 下载文件保存目录(默认 `...\2_unzipped\SH`) |
| SH Degree | 截断阶数:`60 (BA01)` 或 `96 (BB01)`。**96 阶文件保存到 `<目标目录>\deg96\<中心>\`** |
| Download Threads | 并行下载线程数(建议 4) |
| Max Retries | 单个数据集失败重试次数(网络差时调大) |

### 2. 数据集区(Datasets)

勾选要下载的 **中心(CSR / JPL / GFZ)× 任务(GRACE / GRACE-FO)** 组合。

### 3. Technical Notes(低阶项改正数据)

- **Target Directory**:技术说明保存目录(默认 `...\3_Technical Notes`)
- 点击 **"Download Latest Technical Notes"** 下载最新:
  - **TN-14**:C20 / C30 的卫星激光测距(SLR)估计(用于替代 GRACE 自身精度较差的低阶项)
  - **TN-13**:度 1 地心运动改正(CSR / GFZ / JPL 各一份)
- 这些文件为**公开文件,无需 Earthdata 登录**

### 4. 开始 / 取消

- **▶ Start Download**:开始下载
- **■ Cancel**:停止(完成当前文件后停止)

### 5. 日志与进度

- 底部日志实时显示每步状态;
- 汇总表显示每个数据集:发现数 / 匹配度数 / 已有 / 待下载 / 已下载。

## 四、输出文件

下载后的 GSM 文件按中心分子目录存放:

```
<目标目录>/
├── CSR/          # 60 阶:  GSM-2_*_BA01_*
├── JPL/
├── GFZ/
└── deg96/        # 96 阶:  GSM-2_*_BB01_*
    ├── CSR/
    ├── JPL/
    └── GFZ/
```

文件名示例:`GSM-2_2002095-2002120_GRAC_UTCSR_BA01_0600`

| 字段 | 含义 |
|------|------|
| `BA01` | 60 阶(`BB01` = 96 阶) |
| `0600` | GRACE RL06 |
| `0603` | GRACE-FO RL06.3 |
| `UTCSR` | 处理中心(CSR/JPL/GFZ) |

## 五、常见问题

**Q: 登录失败?**
A: 确认用户名/密码正确,并已在 Earthdata 网站注册激活。首次登录有时需在浏览器完成授权。

**Q: 下载失败 / 超时?**
A: 提高"Max Retries"和"Download Threads";检查网络。NASA 服务器偶发不稳定,重试即可。

**Q: 96 阶文件在哪?**
A: 在 `<目标目录>\deg96\<中心>\` 目录下(文件名含 `BB01`)。

**Q: Technical Notes 下载失败?**
A: 单个文件偶发 TLS 握手失败会自动重试;仍失败会在日志标红,可再次点击下载。网络稳定后通常一次成功。

**Q: 怎么把数据变成等效水高(EWH)?**
A: 本软件只负责下载球谐系数与改正数据。从球谐系数到 EWH 还需要其他处理与改正
(如 GIA 等),不在本软件范围内,请结合你的处理流程使用。

**Q: 杀毒软件报警?**
A: PyInstaller 打包的程序偶发误报,可在"病毒和威胁防护 → 保护历史记录"中恢复,或加入白名单。
