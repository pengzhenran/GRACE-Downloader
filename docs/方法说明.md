## 二、球谐系数(GSM)是什么

GSM 文件提供**归一化球谐系数**(C_lm、S_lm),描述该月地球重力场的球谐展开:

```
V(r,θ,φ) = GM/r · Σ Σ (a/r)^l · P̃_lm(cosθ) · (C_lm·cos(mφ) + S_lm·sin(mφ))
```

- 系数越高阶,代表空间尺度越小(分辨率越高);
- 月度解 = 该月平均重力场;
- 这些是**未滤波的系数**,不是直接的水储量/水高图。

### 文件命名

```
GSM-2_2002095-2002120_GRAC_UTCSR_BA01_0600
```

| 字段 | 含义 |
|------|------|
| `BA01` | 60 阶;`BB01` = 96 阶 |
| `0600` | GRACE RL06;`0603` = GRACE-FO RL06.3 |
| `GRAC` / `GRFO` | 卫星任务 |
| `UTCSR` | 处理中心(CSR / JPL / GFZ) |

---

## 三、为什么区分 60 阶与 96 阶

- **60 阶(BA01)**:标准产品,空间分辨率约 300 km,是多数研究的默认选择;
- **96 阶(BB01)**:更高空间分辨率,适合区域尺度研究;
- 两者来自同一 PODAAC 集合,靠文件名中的 `BA01` / `BB01` 区分,下载时按所选度数过滤。

---

## 四、低阶项改正数据(Technical Notes)

GRACE / GRACE-FO 对**低阶项**的估计存在已知局限,通常需要用独立数据替代或补充:

1. **TN-14(C20 / C30 SLR)**
   - C20(扁率项)与 C30 由卫星激光测距(SLR)得到更可靠的估计;
   - 用于替代 GRACE 自身精度较差的 C20 / C30。

2. **TN-13(度 1 地心)**
   - GRACE 在 CM 框架下不直接测定度 1(地心运动)项;
   - TN-13 基于海洋/大气模型反演得到度 1 系数(C10 / C11 / S11),CSR / GFZ / JPL 各一份;
   - 供需要地心改正的处理流程使用。

这些文件在下载器中一键获取,并随数据一起保存,供后续重力场处理时替换或加入。
